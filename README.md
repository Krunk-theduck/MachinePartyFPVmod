# MachinePartyFPVmod
A first person view mod for machine party
  
Features:  
First person view in ALL gamemodes  
First person lobby support  
First person death animations on supported minigames  
First person settings menu for related settings  
  
FULL controller support  
  
To Install:   
1. Download Krunk's Machine Party Mod Loader [Krunk's Mod Loader](https://github.com/Krunk-theduck/MachinePartyModLoader)
2. Head to the link below and download the FPV zip from the release section in Github.
3. Extract the Jarunk-MachinePartyFPV folder into the mods/ folder in your game directory.
4. Play the game.
